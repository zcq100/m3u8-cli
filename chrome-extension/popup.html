      关于

      m3u8-cli 链接检测器

      项目描述

      本扩展用于发现网页中的 m3u8 播放列表，并与本地 m3u8-cli 下载服务配合使用：

      • 监听网络请求并扫描页面，识别 m3u8 地址，支持 iframe 中的播放器
      • 复制链接，或生成带 Referer/Cookie 的 m3u8-cli download 命令
      • 一键提交到 m3u8-cli serve 下载，并在弹窗中查看进度、取消任务

      使用帮助

      1. 安装 CLI

      pip install m3u8-cli

      2. 启动下载服务

      m3u8-cli serve \
  --host 127.0.0.1 \
  --port 8787 \
  --token <token> \
  --output-dir ./downloads

      本机（回环地址）请求免 Token；其他来源需使用与 --token 一致的 Token。

      3. 配置扩展

      在「设置」中确认服务地址（默认 http://127.0.0.1:8787），本机可留空 Token。
